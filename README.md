## 📌 Overview

The **Medicine Inventory Management System** is a completed DBMS mini-project developed using MySQL. It is designed to simplify and organize pharmacy inventory operations through a structured relational database.

The project focuses on maintaining medicine records, managing suppliers, tracking inventory batches, recording stock transactions and monitoring stock discrepancies. It provides an organized approach to handling inventory-related information while demonstrating the practical implementation of database management concepts.

## ✨ Key Features

- 💊 **Medicine Management** – Maintain and organize medicine information.
- 🏥 **Pharmacy Management** – Store and manage pharmacy details.
- 🚚 **Supplier Management** – Maintain supplier information and records.
- 📦 **Inventory Management** – Track medicine stock through individual batches.
- 📊 **Stock Transactions** – Maintain records of stock additions and removals.
- 🔍 **Stock Verification** – Compare recorded inventory with physical stock.
- ⚠️ **Discrepancy Tracking** – Record and manage stock mismatches.
- 📋 **Medicine Reservations** – Maintain medicine reservation records.
- 🔄 **Alternative Medicines** – Store information about substitute medicines.
- 👥 **User Management** – Maintain system user records.

## 🗄️ Database Design

The database is structured around 10 interconnected tables, each responsible for a specific aspect of medicine inventory management.

| Table | Description |
|---|---|
| `Pharmacy` | Pharmacy information |
| `Supplier` | Supplier records |
| `Medicine` | Medicine details |
| `Users` | System user information |
| `InventoryBatch` | Batch-wise inventory records |
| `StockTransaction` | Stock movement records |
| `StockVerification` | Physical stock verification |
| `Discrepancy` | Inventory mismatch records |
| `Reservation` | Medicine reservations |
| `AlternativeMedicine` | Substitute medicine details |
