📌 About The Project

The Medicine Inventory Management System is a database-driven mini project developed to simplify and organize medicine inventory operations.

Managing medicines, suppliers, stock quantities, inventory batches and reservations manually can become complicated and time-consuming. This project aims to provide a structured database solution that helps maintain accurate records and makes inventory-related operations easier to manage.

Built using MySQL, the project demonstrates the practical application of Database Management System concepts through relational database design, SQL queries, constraints and database operations.

🎯 Project Objectives

Design and implement a structured relational database.

Maintain organized medicine and supplier records.

Track medicine stock and inventory batches.

Record stock additions and removals.

Monitor stock discrepancies through verification.

Manage medicine reservations and alternative medicines.

Apply practical DBMS concepts using SQL.

⚙️ Getting Started

Prerequisites

Make sure you have the following installed:

MySQL Server

MySQL Workbench

Git

Installation & Setup

1. Clone the repository

git clone https://github.com/USERNAME/medicine-inventory-management-system.git

2. Navigate to the project directory

cd medicine-inventory-management-system

3. Open MySQL Workbench

Connect to your local MySQL server.

4. Create the database

CREATE DATABASE Medicine_Inventory;
USE Medicine_Inventory;

5. Execute the SQL scripts

Open the SQL files available in the repository and execute them in MySQL Workbench to create the tables, establish relationships and insert sample records.
